OpenAI убрала лимиты на текстовые чаты для бесплатных пользователей ChatGPT

OpenAI отменяет ограничение на количество текстовых сообщений для бесплатных пользователей: со следующей недели Free и Go подписчики смогут общаться с ChatGPT без ограничений.

Лимиты останутся только для других функций — загрузки файлов, изображений и голосового режима. Одновременно компания переводит бесплатных пользователей на модель GPT-5.6 Luna вместо более старой GPT-5.5. На этой же неделе добавляется кнопка Think, которая даёт доступ к расширенному анализу для сложных вопросов.

Для подписчиков Plus и Pro обновляется GPT-5.6 Sol — модель станет точнее с фактическими данными.
