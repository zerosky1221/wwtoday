В Paint запустили Doom — классический шутер играют через графический редактор

Doom теперь играют прямо в Microsoft Paint: графический редактор превращён в монитор для классического шутера. Проект DoomPaint использует условно-бесплатную версию игры — каждый кадр отображается как изображение и может быть сохранён в PNG. По данным разработчиков, проект опубликован на GitHub.
